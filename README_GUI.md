# PDF в Markdown Конвертер с GUI

Современное приложение с графическим интерфейсом для конвертации PDF файлов в формат Markdown.

## 🌟 Особенности

- **Красивый современный интерфейс** - тёмная тема, плавные анимации
- **Пакетная обработка** - конвертация нескольких файлов одновременно
- **Индикатор прогресса** - отслеживание статуса конвертации
- **Кроссплатформенность** - работает на Windows, macOS и Linux
- **Простота использования** - интуитивно понятный интерфейс

## 📋 Требования

- Python 3.8 или выше
- Windows 10/11, macOS 10.15+, или Linux

## 🚀 Установка

### Шаг 1: Установите зависимости

```bash
pip install pymupdf4llm customtkinter packaging
```

### Шаг 2: Запустите приложение

```bash
python pdf2md_gui.py
```

## 💡 Как использовать

1. **Запустите программу** - откроется главное окно
2. **Добавьте PDF файлы** - нажмите "➕ Добавить файлы" и выберите нужные файлы
3. **Выберите папку вывода** - укажите где сохранить Markdown файлы (по умолчанию `./output`)
4. **Настройте опции**:
   - Показать прогресс - отображать статус конвертации
   - Открыть папку после - автоматически открыть папку с результатами
5. **Начните конвертацию** - нажмите "🚀 Начать конвертацию"

## 🎨 Возможности интерфейса

- **Список файлов** - просмотр всех добавленных PDF файлов
- **Управление файлами**:
  - Добавление多个 файлов
  - Удаление выбранных файлов
  - Очистка всего списка
- **Визуальный прогресс** - полоса прогресса и статус операции
- **Уведомления** - сообщения об успехе или ошибках

## 🛠️ Создание исполняемого файла (.exe для Windows)

Если вы хотите создать standalone приложение:

```bash
# Установите PyInstaller
pip install pyinstaller

# Создайте .exe файл
pyinstaller --onefile --windowed --name "PDF2Markdown" --icon=NONE pdf2md_gui.py
```

После компиляции executable файл будет находиться в папке `dist/`.

## ⚙️ Технические детали

- **Библиотека конвертации**: `pymupdf4llm` - обеспечивает качественное извлечение текста и форматирования
- **GUI фреймворк**: `customtkinter` - современные виджеты с поддержкой тёмной темы
- **Многопоточность**: конвертация выполняется в отдельном потоке, интерфейс не блокируется

## 🔧 Решение проблем

### Проблема: Модуль не найден
```bash
pip install --upgrade pymupdf4llm customtkinter
```

### Проблема: Интерфейс выглядит странно
Убедитесь, что у вас установлена последняя версия customtkinter:
```bash
pip install --upgrade customtkinter
```

### Проблема: Конвертация зависает
Большие файлы могут обрабатываться долго. Следите за индикатором прогресса.
